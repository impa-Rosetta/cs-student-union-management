# 教师活动监管中心实施计划

1. 为监管聚合逻辑编写单元测试，覆盖活动归属、WBS 层级、叶子节点进度、逾期/临期、日期汇总和事件过滤。
2. 扩展任务与子任务模型：任务增加稳定的 `activity_id`，任务及子任务增加标准计划起止时间；同步关系存储、Drizzle、PostgreSQL、SQLite 迁移和一致性测试。
3. 扩展任务和子任务创建接口及界面，使新任务保存活动 ID 和计划日期，同时兼容旧的活动名称、截止时间数据。
4. 实现独立的教师监管聚合服务和只读 API，只允许教师与管理员读取全部活动监管信息，拒绝写请求。
5. 用真实监管总览替换当前教师演示工作台，实现搜索、状态/部门筛选、真实统计和活动入口。
6. 实现活动监管详情、WBS 甘特时间轴、逾期/临期提示、折叠层级、只读详情抽屉和操作记录时间线。
7. 增加教师监管接口、页面只读边界、数据库迁移和渲染测试，并补齐可演示的多部门任务数据。
8. 运行完整 `npm run check`，启动本地服务并用教师账号验证总览、时间轴、附件和操作记录。
