# 申请补充与材料管理实施计划

## 目标

实现办公室申请与生活部采购申请在草稿和退回状态下的安全编辑、材料补充、附件管理和重新提交，并以自动化测试验证权限、状态和持久化规则。

## 实施步骤

1. 在接口集成测试中增加办公室申请更新、采购申请更新、越权和非法状态用例，先确认测试失败。
2. 为办公室接口增加统一字段校验、默认材料模板和 `update` 操作，记录领域事件与统一审计。
3. 扩展采购存储层，使基础字段、附件和采购明细可以完整更新；为采购接口增加 `update` 操作和服务端预算重算。
4. 重构办公室表单状态，使新建和编辑复用同一弹窗，并加入材料清单、附件上传、查看、移除、保存及保存后提交。
5. 扩展采购表单，加入编辑入口、明细增删、商品图片、备注、通用附件及预算合计。
6. 增加页面渲染测试，验证编辑入口和材料控件存在。
7. 运行 `npm run typecheck`、`npm run lint` 和 `npm test`，修复回归后检查 Git 差异并提交推送。

## 完成条件

- 两类申请均只能由申请人在可编辑状态下修改。
- 附件和采购明细刷新后保持一致。
- 预算总额由服务端计算。
- 更新操作进入领域时间线和统一审计。
- 构建、类型检查、代码检查和全部自动化测试通过。
